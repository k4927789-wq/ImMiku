# ImMiku 💚

Página estática estilo **Miku Nakano** para subir fotos y videos y compartirlos con un enlace (alojados en Catbox).

## 🚀 Publicar en GitHub Pages

1. Crea un repositorio llamado `ImMiku` en GitHub.
2. Sube estos archivos (`index.html`, `style.css`, `app.js`).
3. Ve a **Settings → Pages → Source: Deploy from a branch → `main` /root** y guarda.
4. Tu página quedará en `https://<tu-usuario>.github.io/ImMiku/`.

> Si quieres la URL corta tipo `https://ImMiku`, GitHub Pages no permite dominios de un solo nivel; puedes usar un dominio propio (p. ej. `immiku.com`).

## ✨ Características
- Arrastra y suelta fotos o videos (máx. 200 MB)
- Barra de progreso y vista previa de imágenes
- Enlace permanente con botón de copiar
- Historial local (guardado en tu navegador)
